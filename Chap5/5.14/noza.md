# 解答

階乗計算機では、再帰呼び出しを行うたびに次の2つの値をスタックへ退避する。

```scheme
(save continue)
(save n)
```

`n = 1` のときに基底条件へ到達するため、`n > 1` の場合は再帰呼び出しが `n - 1` 回行われる。

したがって、退避演算の総数は

```text
2(n - 1)
```

となる。

よって、

```text
退避演算の総数 = 2n - 2
```

と推測できる。

また、各再帰呼び出しでは `continue` と `n` の2つをスタックへ積み、基底条件に到達するまでは `restore` は実行されない。

そのため、スタックの最大深さも再帰の深さに比例し、

```text
2(n - 1)
```

となる。

よって、

```text
スタックの最大深さ = 2n - 2
```

と推測できる。

## 推測結果

```text
退避演算の総数     = 2n - 2
スタックの最大深さ = 2n - 2
```
